# Time Machine Viewer

macOS の Time Machine バックアップの進み具合を、標準の設定画面より詳しく表示するアプリです。

`tmutil status` で段階と全体の進捗を2秒おきに読み、あわせて backupd が統合ログ (`com.apple.TimeMachine`) に書く記録を `log stream` で受け取ります。ログには約1分おきに、いま処理中のファイルのパス、転送速度、容量や項目数ごとの進み、変更検出の進み具合が出るため、それをもとに次のものを表示します。

- 概要: 1件あたりの時間、処理件数、NAS との SMB 通信、バンドを開く時間 (最後の診断) の四つの指標を小さな推移付きで並べ、その下にいま処理中の場所と警告を置く。細かい数値は折りたたんである
- ディレクトリ: どのディレクトリで時間を使ったかの一覧 (区切る階層は変えられます)
- 推移: 同じ時間範囲 (30分、2時間、すべて) で並べた、1件あたりの時間、処理件数、SMB 通信、往復時間、転送速度、進捗のグラフ
- 診断: 管理者パスワードを入れて fs_usage を60秒走らせ、ディスクイメージのバンドを開いた回数と1回の open の時間を集計する。結果は Apple への報告用に英語でコピーできる
- ログ: backupd のログ (頻繁に出るだけの行は省いています)

概要の「どこで時間がかかっているか」では、引き継ぎ1件あたりの時間を、nettop で読んだ SMB 接続 (ポート 445) の往復時間や送受信量と並べます。ここまでは管理者権限なしで動きます。診断だけは fs_usage を使うため、測るたびにパスワードを求めます。

## ビルド

Xcode 16 以降と macOS 15 以降が必要です。

```sh
swift test               # 解析部のテスト
swift run                # そのまま起動
./scripts/bundle.sh      # build/Time Machine Viewer.app を作る
swift scripts/make-icon.swift   # アイコン (Resources/AppIcon.icns) を描き直す
```
